PROJECT6 · VIDEO DESIGN SYSTEM · V1

先定规则，再做每一帧。

这是 Project6 视频的固定设计基准。以后开发任何章节，先阅读本页，再开始构图。Garden 管结构，Galaxy 管组件来源，Emil Skills 管动画品味与审查，GSAP 管执行；本页负责把配色、字体、字号、间距、框架和运动标准锁死。

01 · 配色 Color

Blue 0
#E7F5FF
Blue 4
#4DABF7
Mint 0
#E6FCF5

#63E6BE
主背景：浅蓝 + 薄荷绿，不允许大面积深绿/棕色。
强调色：蓝负责信息与连接，绿负责稳定、完成、运行。
正文：中性深蓝灰，避免纯黑和低对比灰。

02 · 字体与字号 Type

COVER 72–96
Harness
SECTION 42–66
章节主结论
BODY 20–28
口播对应的核心解释文字
META 14–18
状态、编号、辅助信息

统一字体：Noto Sans SC → PingFang SC → Microsoft YaHei → system-ui。Mono 只用于编号、状态、标签。

03 · 框架与间距 Layout

STAGE 1920 × 1080，控制栏永远在舞台外。
GRID 48px 网格，清晰但不抢内容。
SAFE AREA 左右 90–110px，上下 70–90px。
CARD 18/24/34px 三档圆角；卡片之间至少 14–24px。
DENSITY 每屏一个视觉命题，不用“填满空白”代替设计。

04 · 动画 Motion

Agent
ENTRY 320–620ms · ease-out / power3.out
MICRO 100–180ms · 按压 scale .97
CONTINUOUS 2.4–4s · 只用于连接、流动、循环、状态
SYNC TTS SentenceBoundary 触发当前句动画，不提前到下一句

05 · 组件与图标

Galaxy/Uiverse 是组件素材池，先选结构再 Theme 化，不直接复制原始配色。
图标优先 SVG / 线稿 / 自绘；Emoji 只允许做低频辅助，不承担核心信息。
素材图片只做局部视觉资产，不允许整张 AI 生成 UI 冒充页面。
按钮、状态、卡片必须保持同一圆角、边框、阴影体系。

06 · 播放与录制

Manual 不自动翻页；Auto 只在当前 narration ended 后翻页。
播放当前旁白不得缩放/挤压主布局，只允许内容元素做 opacity / translate。
录制完成只下载浏览器本地，不上传服务器。
HTTPS 优先用原生标签页捕获；HTTP 使用 Canvas 兼容录制模式。
开发门禁：每次改视频前先看本页 → 当前 PRD / Active Decisions → 当前章节 Acceptance → Garden → Emil Review。视觉变更如果破坏本页 token，必须先更新本页并说明原因，不能在章节里偷偷漂移。
