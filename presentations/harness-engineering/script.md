Prompt 写得再漂亮，Agent 还是可能把事情做砸。

---

因为一个真正能工作的 Agent，面对的从来不只是模型。它还要拿到上下文、调用工具、执行多步任务、记住状态、判断结果，出了错还得自己回来修。

---

所以今天更值得关注的，不只是 Prompt Engineering，而是 Harness Engineering。你可以把它理解成：给 Agent 搭一整套“工作环境”。

---

Prompt 决定这一句话怎么问；Harness 决定模型能看到什么、能调用什么、任务怎么往下走，以及失败以后怎么恢复。

---

举个最简单的例子。你让 Agent 帮你研究十家公司。只靠 Prompt，它可能给你十段看起来很像答案的文字；有了 Harness，它会自己搜索、读网页、整理表格、保存进度，再回来检查漏没漏。

---

所以真正决定 Agent 能不能稳定工作的，往往不是那一句提示词，而是提示词外面这一整套系统。下一章，我们把这套系统一层一层拆开看。
