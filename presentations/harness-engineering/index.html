OUTSIDE THE MODEL

你可以把 Harness 想成 Agent 的工作台

Agent真正执行任务

Context

它现在应该看到哪些资料？哪些内容不该塞进去？

Tools

搜索、数据库、文件、浏览器，什么时候该调用哪个？

State

做到第几步了？之前查过什么？哪些结论已经确认？

Recovery

失败以后是重来，还是从上一步继续？怎么避免反复犯错？

PROMPT ≠ HARNESS

一个管“怎么说”，一个管“怎么把事做完”

Prompt

INSTRUCTION
“你这样做”
像你跟一个员工交代任务：目标是什么、格式是什么、注意什么。

Harness

WORK ENVIRONMENT
“东西都给你备好”
电脑 / 工具
资料 / 上下文
流程 / 状态
检查 / 恢复
不是多写几句 Prompt，而是让 Agent 真的有条件把任务跑完整。
A REAL TASK

让 Agent 研究十家公司，差别马上就出来了

检索资料
记录来源
检查缺口
继续下一家

不是“搜完就写”
而是一家公司一家公司闭环

查 → 记 → 检查 → 补缺口 → 确认，再进入下一家公司。Harness 把一次模糊任务变成可执行、可恢复的循环。
