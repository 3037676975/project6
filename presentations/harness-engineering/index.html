CHAPTER 01 · PROMPT VS HARNESS
Instruction vs Operating Environment

Prompt 管“怎么说”，Harness 管“怎么把事做完”

PROMPT

一句指令

像你对一个员工说：这件事你这样做。

“帮我研究 10 家公司，整理它们的产品、融资和竞争优势，并给出结论。”
INSTRUCTION
PROMPT
HARNESS CONTROL PLANE

完整工作环境

01Context哪些资料可以看，当前任务是什么。
02Tools搜索、浏览器、数据库怎样调用。
03State做到哪一步，中间结果放在哪里。
04Recovery失败后怎样检查、重试、继续。
Prompt = instruction告诉它要做什么
Harness = environment保证它真的能做完

CHAPTER 01 · TAKEAWAY
Remember this one sentence

模型决定它有多聪明，
Harness 决定它能不能稳定做完

真正可靠的 Agent，是模型能力和运行系统一起工作的结果。后面我们再把这张“工作台”一层一层拆开。

CONTEXT看见正确的信息任务、资料和约束都在正确位置。
TOOLS调用正确的能力搜索、数据库和外部系统都能执行。
STATE记住执行过程多步任务不会因为一次切换而丢失进度。
RECOVERY失败之后还能回来检查、重试和继续成为系统的一部分。
