最终目标

不是回答一句话，而是把事情稳定做完。

Prompt vs Harness

把 Agent 想成一个聪明员工

Prompt

告诉他：这件事怎么理解、怎么回答。

→

Harness 是整个工作环境

资料在哪Context / Memory
工具在哪Tools / APIs
进度怎么记State / Checkpoint
出错怎么办Retry / Recovery
真正的问题不是“提示词够不够长”，而是“它有没有条件把事情做完”。
A real task

没有 Harness：
“搜一轮，然后直接写答案”

有 Harness：每家公司都走同一套可追踪流程。查完一家公司，记录来源、检查缺口，再进入下一家。
