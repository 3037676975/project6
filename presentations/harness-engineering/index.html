CHAPTER 01 · PROMPT VS HARNESS
Instruction is only one layer of the operating environment

Prompt 管“怎么说”，Harness 管“怎么做完”

HARNESS · OPERATING ENVIRONMENT
PROMPT · INSTRUCTION

一句任务说明

它告诉 Agent：你希望它做什么、怎么回答、遵守哪些要求。

“帮我研究 10 家公司，并给出结论。”
01 · INPUTContext决定模型现在能看到什么。
02 · CAPABILITYTools决定模型真正能调用什么。
03 · CONTINUITYState决定多步任务怎样继续。
04 · RESILIENCERecovery决定失败后怎样恢复。
Prompt 是里面的一张“任务单”；Harness 是整个工作环境。
