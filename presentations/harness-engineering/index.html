真正能工作的环境

Context知道当前任务背景和缺口
Tools知道能调用什么、怎么调用
State执行到一半不会忘记
Recovery失败以后能继续，而不是重来
Prompt 像一句工作要求；Harness 像整套办公环境和流程。
A real task

比如：研究十家公司

查资料
记来源
看缺口
继续下一家

同一个任务，执行方式完全不同

Harness 让每家公司都走同一套可追踪流程：查资料、记来源、检查缺口，再进入下一家。

无 Harness：搜一轮 → 直接总结
有 Harness：执行 → 检查 → 继续
