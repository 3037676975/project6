# Harness Engineering · 整片验收标准 v55

> 当前正式产品构建：**Project6 v55**。正式播放器缓存参数统一为 `?v=55`，专用录制页为 `record.html?v=55`。

## 当前验收对象

- 完整视频：42 Scene
- TTS：整片一次 JSON / 一次 ZIP
- Recording：专用录制控制台 + 精确成片框裁切 + 播放器/录制双状态机

## Gate F · 本地录制 v55
状态：**REVIEW**

验收要求：
- [x] `.stage-frame` 是唯一成片边界，Canvas 每帧按真实坐标裁切。
- [x] 所有 REC / 控制状态均在成片框外，不进入最终视频。
- [x] 上一页 / 下一页由录制页直接控制 Scene 进度，不依赖主播放器私有状态。
- [x] 自动播放由录制页独立 Scene 定时器驱动。
- [x] 暂停画面只暂停自动推进与 GSAP，不暂停 MediaRecorder。
- [x] 录制本身有独立四态：开始、暂停/继续、停止并保存、取消并丢弃。
- [x] 暂停录制使用 `MediaRecorder.pause()/resume()`，暂停时间不计入有效 REC 时长。
- [x] 取消录制不会生成下载文件。
- [x] 旁白开关可用。
- [x] 本地配乐可选择、播放/暂停并调节音量。
- [x] 最终输出固定 1920×1080，目标 60fps / 18 Mbps。
- [ ] 用户实机确认：录制前上一页/下一页/自动播放/暂停画面可用。
- [ ] 用户实机确认：录制开始后上述四个画面控制仍可用。
- [ ] 用户实机确认：暂停录制/继续录制可用。
- [ ] 用户实机确认：停止并保存可下载正常文件。
- [ ] 用户实机确认：取消录制不下载文件。
- [ ] 用户实机确认：最终文件只含中间 16:9 动画且可播放。

## 版本一致性 Gate

以下任意一项出现即 FAIL：
1. 当前版本不是 v55；
2. `record.html` / `record-v55.js` / `full-video.html` 缓存参数不一致；
3. 页面版本与 `assets/version.js` 不一致；
4. 页面升级而 DEVELOPMENT_STATUS / ACCEPTANCE 未同步。

## 当前结论

v55 不再让录制页控制依赖主播放器闭包中的 `playing / paused` 状态。画面控制与录制控制使用两套互不锁定的状态机，目的是彻底解决“开始录制后播放/翻页按钮失效”的问题。
