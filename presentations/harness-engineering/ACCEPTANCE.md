## Gate F · 本地录制 v53
状态：**REVIEW**

验收要求：
- [x] `.stage-frame` 是唯一成片边界，Canvas 每帧按真实坐标裁切。
- [x] 所有 REC / 控制状态均在成片框外，不进入最终视频。
- [x] v53 不再使用“可见按钮转发隐藏按钮”的桥接方式。
- [x] 录制页可见的 `上一页 / 自动播放 / 暂停 / 下一页` 就是 Garden 播放器真实 `prevBtn / playBtn / pauseBtn / nextBtn`。
- [x] 旁白开关可用。
- [x] 本地配乐可选择，显示文件名与时长，可播放/暂停并调节音量。
- [x] 配乐播放状态独立维护；录制开始时按用户选择从 0 秒播放。
- [x] 开始 / 停止录制与 REC 计时可用。
- [x] 最终输出固定 1920×1080，目标 60fps / 18 Mbps。
- [ ] 用户实机确认：上一页可用。
- [ ] 用户实机确认：自动播放可用。
- [ ] 用户实机确认：暂停/继续可用。
- [ ] 用户实机确认：下一页可用。
- [ ] 用户实机确认：配乐状态、播放、音量正确。
- [ ] 用户实机确认：最终文件只含中间 16:9 动画且可播放。

## 版本一致性 Gate

以下任意一项出现即 FAIL：
1. 当前版本不是 v53；
2. `record.html` / `record-v53.js` / `full-video.html` 缓存参数不一致；
3. 页面版本与 `assets/version.js` 不一致；
4. 页面升级而 DEVELOPMENT_STATUS / ACCEPTANCE 未同步。

## 当前结论

v52 的按钮失效根因是录制页使用代理按钮去 `.click()` 隐藏播放器按钮。v53 删除这层代理，直接把可见按钮交给 Garden 播放器本身绑定。
