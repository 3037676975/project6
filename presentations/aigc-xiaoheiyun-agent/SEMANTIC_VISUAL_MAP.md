## 动画原则

1. **口播 Cue 决定动画出现时间**，不允许页面加载后所有信息一起出现。
2. 时间关系用「沿路径移动」；架构关系用「连线绘制 + 节点激活」；对比关系用「滑杆 / 两侧转场」；状态关系用「节点流转」；检索关系用「漏斗收敛」。
3. 每个 Scene 只有一个主运动语言，辅助动画只服务理解，不做无意义满屏漂浮。
4. 主画面保持 Project 001 的 warm-keynote / Garden 气质，VideoShotCraft 负责镜头语法而不是替换设计风格。
5. Scene 006、009、015、030、031、034、035、038、039、040 作为高信息密度重点 Scene，优先检查其逻辑可读性和动画节奏。
