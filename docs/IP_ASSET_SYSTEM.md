# Project6 · IP 制作与公共资产系统

## 定位

IP 制作是 Project6 的跨视频公共资产层，不属于任何单个视频 Project。

当前首个 IP：**AIGC小黑云**。

一句话定位：**把难懂的 AI 工程，讲成人话。**

## 为什么存在

视频项目只负责内容与成片；IP 层负责长期复用的角色、机器、道具、教学比喻和视觉容器。

固定调用顺序：

```text
新视频 / 新 Scene
→ 先查 IP 公共资产池
→ 已有：缩放 / 镜像 / 裁切 / HTML 组合复用
→ 缺少：只生成 missing assets
→ 按角色锁定块验收
→ 验收通过后回收入公共池
→ 当前视频只读取 / 复制，不反向修改公共母版
```

## AIGC小黑云 v1 当前资产

- 主持人动作：24
- AI 系统机器：6
- 案例道具：6
- 教学比喻：6
- 空白卡片：6
- 总计：48 个可复用独立资产

## 角色不可修改识别点

- 巨大、不规则的炭黑水彩云团脑袋
- 两只等大的白色圆眼与小黑瞳
- 小猫嘴，每侧三根白色胡须
- 短小黑色身体
- 橙到红渐变、几何纹样、带流苏的围巾

禁止真人化、动漫美女化、增加头发、眼镜、鞋或额外服装。

## 视觉原则

- 炭黑：角色轮廓 / 正文
- 暖米白：主画布
- 青绿：系统 / 正确路径
- 围巾橙：重点 / 能量
- 珊瑚红：风险 / 错误
- 图片负责人物、机器、复杂插画
- 中文、代码、标题、字幕由 HTML 生成
- 不使用紫粉霓虹科技感作为默认风格

## 提示词系统

提示词分为：

1. **锁定块**：IP 身份和视觉风格，长期不可随单期视频修改。
2. **变量块**：课程、章节、概念、比喻、动作、资产类别、构图、背景等。

每次生成前必须先查公共池，只为 `missing assets` 生成。

## 当前后台入口

`ip.html`

后台支持：

- 查看 IP 定位与角色红线
- 查看 48 个资产 Manifest
- 按主持人 / 机器 / 道具 / 比喻 / 卡片筛选
- 本地导入原始 IP 资产 ZIP
- JSZip 自动识别 48 个 PNG
- IndexedDB 在当前浏览器持久保存素材包
- 清除本地素材包
