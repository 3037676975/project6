这里不是“特效大全”，而是 Project6 的动画设计与验证层。Garden 决定 Scene 结构，Emil Skills 判断动画是否合理，GSAP 负责真正执行；动画最终必须回到具体视频场景里接受阅读和叙事检验。

核心原则：动画的职责是解释、建立空间关系、表示状态和避免突兀变化。观众正在阅读的文字必须稳定；“更炫”不是合格理由。

Project6 动画制作链

① Garden先确定 Chapter / Scene / Narration 边界。
② Find OpportunitiesEmil：判断哪里真的值得动，主动拒绝无意义动画。
③ Animate / Vocabulary确定目的、空间故事、属性、曲线、时长和退出方式。
④ GSAP RuntimeTimeline / DrawSVG / MotionPath / Flip / Morph 等执行。
⑤ Review / Improve按动画标准审核，再做高杠杆优化。

Emil Review 快速检查

Why?

每个动画必须能说清楚是 Explanation、Spatial、State、Feedback 还是 preventing jarring change。

Physicality

不从 scale(0) 凭空出现；同一对象要有来源和去向，进入后保持稳定。

Performance

普通 UI 优先 transform / opacity；SVG path 只在解释关系时使用。

Timing

UI 反馈保持快速；解释动画按 narration 语义决定，不用统一固定时长。

Accessibility

必须支持 prefers-reduced-motion；hover 只给真正的鼠标/触控板。

Reject motion

文字阅读时持续漂移、无意义呼吸、无限 runner、整屏 simultaneous pop 都应删除。
