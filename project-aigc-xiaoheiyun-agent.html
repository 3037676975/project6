② 已核对的 LangChain 最新资料

教程口径按 2026 官方信息校准，不再把 LangChain 讲成“把 Prompt 串起来的链”。

LangChain当前核心是 Agent framework：create_agent、模型/工具抽象、集成与 middleware。
LangGraph更底层的 agent runtime / orchestration，负责状态、持久化、人工介入、重试和复杂流程。
两者关系LangChain 的 agent 构建在 LangGraph durable runtime 上；简单 Agent 用 LangChain，复杂可控工作流下沉 LangGraph。
官方资料入口：langchain.com/oss-overview · langchain.com/langchain · langchain.com/langgraph · reference.langchain.com
