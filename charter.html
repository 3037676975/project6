PROJECT-FIRST · LOCAL TTS · GARDEN

一个视频，就是一个独立项目。

Project6 已废弃“视频工作台”。现在每个作品内部直接管理口播稿、Garden 画面、第1张～第N张、本地 IndexTTS JSON、回传配音、本地音画预览，以及最后阶段的动画音效。

01 口播稿先把完整 Narration 写清楚
02 Garden 画面按 Chapter / Step 生成
03 用户确认逐张 / 逐章验收
04 本地 TTS复制 JSON → IndexTTS
05 本地预览ZIP 回传自动匹配
06 动画 SFX最后才添加

正式生产链

用户给主题 / 文章 → AI 写完整口播稿 → 拆 Chapter / Step → Garden 生成每张画面 → 用户确认口播 + 画面 → 解锁 TTS JSON → 本地 IndexTTS 2.5 → ZIP 上传对应作品 → 自动 001 ↔ 第1张 → 本地音画预览 → 最后动画 SFX / BGM

配音 vs 动画音效

配音：IndexTTS 生成的人物声音，001、002、003……必须和对应视频画面放在同一个作品里。

动画音效：元素出现、whoosh、click、pop、confirm 等短 SFX，只在音画预览通过后添加。第一批使用真实 Kenney CC0 资源。

强制开发规则

  • 每次先读 Charter → PRD → Active Decisions → Development Status → 当前 Acceptance。
  • 页面改动后，同一轮必须更新状态与验收文档。
  • 禁止恢复 studio.html / #/studio。
  • 禁止假按钮、假数据、假资源。
  • 第一章没通过，不开发第二章。
